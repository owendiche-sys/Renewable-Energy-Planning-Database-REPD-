# \## Overview  

# 

# This project analyses real-world \*\*Wind Turbine SCADA (Supervisory Control and Data Acquisition)\*\* data to explore turbine performance, operational behaviour, and key relationships between wind conditions and electrical output.

# 

# SCADA datasets contain high-frequency operational measurements (such as wind speed, active power, theoretical power, and wind direction). These allow us to evaluate turbine efficiency, detect potential underperformance, and gain insights into wind energy production.

# 

# This project demonstrates skills in \*\*data cleaning, exploratory analysis, time-series handling, visualisation, and renewable energy analytics.\*\*

# 

# ---

# 

# \## Objectives  

# 

# \- Load and preprocess Wind Turbine SCADA data  

# \- Explore operational behaviour and performance metrics  

# \- Visualise relationships between wind speed and active power  

# \- Compare actual output to theoretical power curves  

# \- Analyse temporal patterns (daily and monthly trends)  

# \- Generate insights relevant to turbine efficiency  

# 

# ---

# 

# \## Key Insights  

# 

# \- Active power increases non-linearly with wind speed, following typical turbine behaviour  

# \- Daily and monthly trends provide insight into turbine performance across time  

# \- Theoretical vs actual power comparison shows relative performance    

# \- Preliminary anomaly detection suggests possible underperformance intervals
